# Qualtor 项目术语

本词汇表区分生成产品、实验编排、测试评测和指标计算，避免把完整评测流程简称为“算分”。

## 术语

**生成产品（agents）**：根据已有代码自动生成、验证、修复单元测试，并保存测试快照的完整交付物。

**实验编排（runner）**：组织题目、生成配置及多次试验，将生成产品与独立测试评测连接起来的实验过程。

**测试评测（assessment）**：对已保存测试快照的有效性、稳定性、缺陷检出、抗误报、覆盖范围和生成成本进行独立评价的完整过程。
_避免_：用 scorer 或 score 指代整个评测模块。

**判定与指标计算（judge）**：将编译、运行和分析记录转为状态、计数与指标的确定性规则。

**试验（trial）**：同一道题从全新工作区开始完成的一次生成尝试过程，包含预算内修复和首次、最终产物。

**运行（run）**：一次实际执行及其记录；批量评测运行可包含多道题、每题多个 trial。

**测试快照**：某个时刻测试文件的固定副本，附带文件清单和内容哈希，使编译、运行或评测结果能够对应到确定的测试内容。

**本轮测试快照**：一次编译验证开始前保存的测试快照。Agent 后续修改工作区中的测试，不改变这份快照。
_表述_：编译前保存本轮测试快照。

**首次／最终测试快照**：首次编译前和生成结束时分别保存的测试快照，供生成结束后的独立评测使用；从未编译时，两份快照都取结束时的测试。

**冻结产物**：既有文档和接口中对固定测试文件及其哈希清单的称呼；在生成流程说明中统一称为“测试快照”。

**稳定有效测试**：在原始被测代码上通过，并通过重复、乱序及单独运行检查的测试。
