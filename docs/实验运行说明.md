# C++11 Docker 工具链运行说明

从项目根目录运行，宿主机需要 Python 3.9+ 与 Docker。入口只校验仓库中已有的源码快照，不自动更新上游。

```bash
python3 evaluator/toolchains/toolchains.py
python3 evaluator/toolchains/toolchains.py --skip-build
```

默认构建并验收 GCC、Clang 两个镜像；`--build-only` 只构建，`--toolchain gcc` 或 `--toolchain clang` 选择工具链，`--platform linux/arm64` 或 `linux/amd64` 指定架构。pi 在宿主机安装和运行，入口为 `python3 agents/setup.py --pi-only`。

每次新建 `runs/<run-id>/`，已有 ID 拒绝覆盖。`run.json` 的 `kind` 为 `toolchain`；`evidence/` 保存输入哈希、镜像、容器与命令日志，`gcc/`、`clang/` 保存实际构建、测试和分析结果，`summary.json` 汇总。

| 路径 | 内容 |
|---|---|
| `evaluator/toolchains/toolchains.py` | 构建镜像、启动容器、汇总验收 |
| `agents/toolchains/docker/` | 产品 GCC 镜像定义和构建上下文，评测复用 |
| `evaluator/toolchains/docker/` | 评分专用 Clang/Mull 镜像定义和构建上下文 |
| `evaluator/toolchains/check_toolchain.py` | 容器内验收 |
| `evaluator/toolchains/smoke/` | 9 个 C++11 GoogleTest 冒烟测试 |
| `evaluator/common/` | 统一路径、审计、覆盖率解析、源码校验 |
| `benchmark/gildedrose-update-quality/source/` | 完整上游 cpp 快照、SOURCE.json、需求说明、许可证 |

GCC/Clang 验收时源码和测试只读挂载；执行容器禁网、非 root、根文件系统只读，限制 CPU、内存与进程。构建阶段可联网下载固定版本依赖。工具版本、安装摘要和接入细节见 [C++11 固定工具链](C++11固定工具链.md)，评分入口见 [评分器运行说明](评分器运行说明.md)。
