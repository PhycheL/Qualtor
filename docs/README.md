# Qualtor 文档索引

项目目标是让大模型生成 C++ 单元测试，评价测试质量，并据此改进 Agent 和 skill。当前提供两套固定版本的 C++11 Docker 工具链；评分器已在 Linux ARM64 完成 GildedRose 分母标定和 16 个样本的完整校准。模型测试生成与预算内修复仍待接入。

先看规划和运行说明，需要核对结果时再看报告与原始证据。
