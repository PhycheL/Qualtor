# Qualtor 文档索引

项目目标是生成 C++ 单元测试并独立评价质量与成本。按 D013，`agents/` 是可独立交付产品：pi 在宿主机运行，生成测试在 Docker 编译并反馈；`evaluator/` 负责批量实验和评分。评分器 0.1.4 已通过 GildedRose 的 16 个样本各两次 Linux ARM64 校准，沿用 47 个冻结变异。当前命令和本轮证据见运行说明。

## 文档维护

项目规划和报告放在 `docs/`，随产品交付的说明放在 `agents/README.md`、`agents/docs/`，均在本索引登记。根 README 提供目录导览；`AGENTS.md` 维护协作入口，执行要求集中在[执行细则](项目协作指令.md)。

文档中的历史命令和原始日志保留执行时的路径；当前阅读入口以本索引和文档链接为准。实验代码、源码快照、测试数据和构建产物不作为说明文档搬迁。
